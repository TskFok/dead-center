# 屏幕百分比准星与细旗贴边向心设计

## 目标

将所有准星预设的“整体尺寸”从固定像素改为目标屏幕百分比，并让“细旗空心菱形”的四条旗臂真正从目标屏幕四边向中心延伸，而不是仅贴住 256×256 的准星窗口边缘。

## 已确认的产品语义

- “整体尺寸”统一使用 `0%` 到 `100%`，步进为 `1%`。
- 圆环、十字及除“细旗空心菱形”外的菱形预设保持正方形比例，尺寸以目标屏幕逻辑短边为基准。
- “细旗空心菱形”使用完整目标屏幕作为画布：
  - 四条旗臂外端始终分别锚定上、右、下、左屏幕边缘。
  - `0%` 仍显示约等于当前线宽的最短旗头。
  - 百分比越高，旗臂从屏幕边缘向中心延伸得越长。
  - `100%` 时旗臂尖端停在中心缺口或空心菱形外缘，不覆盖中心标记。
  - 中央空心菱形始终保留。
- 新安装默认整体尺寸为 `3%`。旧配置按目标屏幕逻辑短边换算，尽量保持升级前的视觉尺寸。

## 方案选择

采用单个全屏透明覆盖层。覆盖层始终与当前解析出的目标屏幕同宽同高，内部再根据预设决定使用居中的正方形准星或铺满屏幕的细旗画布。

未采用按预设动态改变窗口尺寸的方案，因为它会让每次预设切换和尺寸拖动都触发原生窗口几何变化，容易出现闪烁与跨平台差异。未采用四边加中心的多窗口方案，因为多个置顶、透明、鼠标穿透窗口会显著增加多显示器同步复杂度。

## 覆盖层窗口与多显示器几何

后端把当前固定 `256×256` 逻辑像素的覆盖层改为目标屏幕全尺寸：

- 位置直接使用目标屏幕物理坐标原点 `(x, y)`。
- 窗口逻辑宽高分别为 `physical_width / scale_factor` 和 `physical_height / scale_factor`。
- 新建覆盖层和刷新已有覆盖层共用同一个几何计算结果，同时设置窗口尺寸、位置、始终置顶、不可聚焦与鼠标穿透属性。
- 切换目标屏幕、显示器配置发生变化或离线屏幕回退主屏时，都重新计算完整窗口几何，而不只更新中心位置。
- 视觉参数变化不需要调整原生窗口尺寸；覆盖层始终全屏，可避免拖动滑杆时频繁改变窗口。

几何计算保持为独立纯函数，输入 `MonitorGeometry`，输出物理位置和逻辑尺寸，便于覆盖负坐标、高 DPI、横屏与竖屏测试。

## 配置协议与迁移

设置协议升级为版本 2：

- TypeScript 与 Rust 的 `VisualSettings.sizePx` 改为 `sizePercent`。
- 默认值为 `3`，规范化范围为 `0` 到 `100`。
- `AppSettings.version` 从 `1` 升为 `2`。
- 配置预检同时识别版本 1 和版本 2，版本 1 不能被当作损坏文件备份。
- 加载版本 1 时，保留所有其他字段，并按以下公式迁移：

  `sizePercent = sizePx / logical_short_edge × 100`

  其中 `logical_short_edge = min(physical_width, physical_height) / scale_factor`。目标屏幕仍可解析时使用该屏幕；目标屏幕离线时使用现有主屏回退规则。无法取得显示器几何时使用新默认值 `3%`。
- 迁移结果限制在 `0%` 到 `100%` 并立即持久化为版本 2，避免每次启动重复迁移。
- 版本 2 仍沿用现有损坏 JSON 备份机制；未知版本继续视为不支持，不静默套用错误语义。

## 前端渲染

### 普通预设

覆盖层根元素和设置页预览区都作为可测量的渲染画布。除“细旗空心菱形”外，准星根元素保持等宽等高，其边长为画布短边乘以 `sizePercent / 100`，并继续使用现有颜色、透明度、线宽、缺口与各预设内部比例。

`0%` 时普通预设允许收缩为不可见；这是统一百分比尺寸的直接结果。线宽和中心缺口仍使用像素单位，不随屏幕百分比缩放。

### 细旗空心菱形

“细旗空心菱形”根元素改为铺满渲染画布，中央菱形定位在画布中心。四条旗臂分别固定在对应边缘，继续使用现有向心 `clip-path`。

每条旗臂的可用最大长度是对应轴的一半减去中心净空。实际长度按 `sizePercent` 在线性区间内插，并用当前线宽作为最小可见长度：

`arm_length = max(flag_thickness, progress × (axis_length / 2 - center_clearance))`

其中 `progress = sizePercent / 100`，`center_clearance` 包含旋转后空心菱形的半径和 `gapPx / 2`。因此 `0%` 显示贴边短旗头，`100%` 精确停在中心标记外缘或用户设置的额外缺口外缘。

中央菱形沿用强调色、空心细描边和阴影规则，不随旗臂进度消失。

## 设置页与预览

- “整体尺寸”滑杆改为 `0–100`，输出后缀改为 `%`。
- 预览区继续使用现有外层布局，在内部增加一个按当前解析屏幕逻辑宽高比等比适配的预览画布；剩余空间作为留边，不参与准星尺寸计算。
- 普通预设按该预览画布短边显示百分比效果；“细旗空心菱形”铺满该画布并贴住四边。
- 选择不同目标屏幕后，预览画布更新为新屏幕宽高比；目标屏幕离线时显示实际回退屏幕，覆盖层几何同步刷新。
- 自动保存、防抖与其他控件行为保持不变。

## 错误处理与兼容性

- 没有可用显示器时沿用现有中文错误提示和重试入口，不创建错误尺寸的覆盖层。
- 目标屏幕离线时沿用主屏回退状态，并按回退屏幕重新计算百分比尺寸和窗口几何。
- 透明、无边框、始终置顶、不可聚焦、系统托盘和鼠标穿透行为保持不变。
- 本次不引入数据库、网络请求或新的运行时依赖，也不改变其他视觉参数的单位。

## 测试策略

### Rust

- 覆盖层几何纯函数：普通屏、负坐标屏、高 DPI、横屏和竖屏。
- 版本 1 配置迁移：目标屏幕可用、目标离线回退、无显示器默认值、上下界限制和其他字段保留。
- 版本 2 配置规范化与序列化字段名。
- 版本预检：版本 1、版本 2、未知版本和损坏 JSON。

### TypeScript / React / CSS

- 默认设置和规范化使用 `sizePercent: 3` 与 `0–100`。
- 设置页滑杆显示 `%`、范围正确，并防抖保存 `sizePercent`。
- 普通预设把百分比映射为画布短边尺寸。
- “细旗空心菱形”填满画布、四边锚定、0% 保留最短旗头、100% 停在中心净空外缘。
- 其他六种预设的结构、颜色、线宽、缺口和中心标记保持回归通过。
- 运行完整前端测试、Rust 测试和生产构建。

## 成功标准

- 实际覆盖层与所选目标屏幕四边完全对齐，包括负坐标和高 DPI 显示器。
- 所有预设的“整体尺寸”均以目标屏幕百分比保存和显示。
- 普通预设以目标屏幕短边为 100% 基准且不变形。
- “细旗空心菱形”在 0% 时四边均有可见短旗头；百分比增加时持续向中心延伸；100% 时不覆盖中心缺口或空心菱形。
- 版本 1 配置可迁移且不会被误判为损坏。
- 其余设置、预设、多屏回退和托盘行为无回归。

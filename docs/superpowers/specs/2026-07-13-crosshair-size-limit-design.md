# 准星大小上限扩展设计

## 目标

将准星整体尺寸的可配置上限从 96px 提高到 192px，同时确保大尺寸准星在桌面覆盖层中完整显示且仍以目标显示器中心定位。

## 方案

- 设置页“整体尺寸”滑杆保持最小值 12px，将最大值改为 192px。
- TypeScript 前端配置归一化和 Rust 后端配置归一化都使用 12–192px，避免界面、内存状态和持久化配置出现不同边界。
- Tauri 覆盖层窗口从固定 128×128px 放大到固定 256×256px，为 192px 准星在四周各保留 32px 空间。
- 覆盖层继续使用现有的逻辑尺寸和显示器缩放因子计算中心位置，不引入动态窗口缩放。
- 默认准星尺寸继续保持 32px，其他视觉参数边界不变。

## 数据流与兼容性

用户在设置页选择尺寸后，视觉配置沿用现有保存和事件通知链路。旧配置无需迁移；原本合法的 12–96px 数值保持不变，96–192px 的新数值不再被前后端截断。超过 192px 的外部或损坏配置统一归一化为 192px。

## 测试

- 前端设置归一化测试验证超大尺寸被限制为 192px。
- 设置页测试验证“整体尺寸”滑杆暴露 192px 最大值。
- Rust 配置测试验证超大尺寸被限制为 192px。
- 覆盖层定位测试使用 256px 逻辑窗口尺寸验证高 DPI、负坐标显示器上的居中结果。
- 最后运行前端测试、Rust 测试、类型检查及构建检查。

## 非目标

- 不改变默认尺寸。
- 不让覆盖层窗口随准星尺寸动态变化。
- 不调整准星图形比例、线宽上限或中心缺口上限。

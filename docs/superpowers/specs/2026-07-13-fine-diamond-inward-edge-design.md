# 细旗空心菱形贴边向心设计

## 目标

把“细旗空心菱形”的四条旗臂改为从准星容器边缘向屏幕中央延伸，同时保留细旗厚度、中心空心菱形、颜色、尺寸、透明度和中心缺口调节能力。

## 方案

仅调整 `fine-diamond` 的 CSS 几何规则，不增加预设或设置字段：

- 将旗臂外侧内缩量从 `22%` 改为 `0%`，使上、右、下、左四条旗臂分别贴住容器对应边缘。
- 将四条旗臂的尖头从朝外改为朝向中心空心菱形。
- 保留现有旗臂厚度、中心净空、菱形尺寸和描边规则。
- 其他三种菱形预设保持不变。

## 验证

在组件测试中读取 `fine-diamond` 的几何声明和四向裁剪多边形，验证外侧内缩为零、四个尖头均朝向中心。继续运行现有前端测试和构建，确认中心缺口响应、极端尺寸约束以及其他预设没有回归。

## 成功标准

- “细旗空心菱形”四条旗臂均从准星容器边缘开始。
- 每条旗臂的尖头均指向中央空心菱形。
- 中央菱形仍为空心，细旗视觉厚度不变。
- 其余六种准星的结构和行为不变。
